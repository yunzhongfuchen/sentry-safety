# Sentry 前端设计文档

## 1. 页面结构与导航

### 1.1 页面顺序

| 顺序 | 页面 | 路由 | 说明 |
|------|------|------|------|
| 1 | 监控中心 | `/multi` | 主副画面实时视频流 |
| 2 | 记录查询 | `/records` | 历史告警记录与帧查看 |
| 3 | 系统设置 | `/settings` | 全局参数、摄像头管理、画框配置 |

### 1.2 导航方式

顶部固定导航栏，三个页面切换：

```
┌─────────────────────────────────────────────────────────────┐
│  Sentry 安全监控系统      [监控中心] [记录查询] [系统设置]      │
└─────────────────────────────────────────────────────────────┘
```

当前页面高亮，其余为普通态。

## 2. 监控中心 (Monitor)

### 2.1 布局结构

```
┌──────────────────────────────────────────────────────────────┐
│  Header: Sentry 安全监控系统   [监控中心] [记录查询] [系统设置]   │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌──────────────────────────────────┐  ┌────────────────┐  │
│  │                                  │  │ 副画面 1        │  │
│  │                                  │  ├────────────────┤  │
│  │         主画面 (MJPEG)            │  │ 副画面 2        │  │
│  │       (带检测框标注)              │  ├────────────────┤  │
│  │                                  │  │ 副画面 3        │  │
│  │                                  │  ├────────────────┤  │
│  │                                  │  │ 副画面 4        │  │
│  │                                  │  ├────────────────┤  │
│  │                                  │  │ 副画面 5        │  │
│  │                                  │  ├────────────────┤  │
│  │                                  │  │ 副画面 6        │  │
│  └──────────────────────────────────┘  ├────────────────┤  │
│                                         │ [<] [页码] [>] │  │
│                                         └────────────────┘  │
├──────────────────────────────────────────────────────────────┤
│  [画框配置]  [告警列表]                                       │
│  在线: N | 检测中: M | 总告警: X | 运行时间: T                │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 主画面

- 大尺寸，占左侧主要区域
- 显示单个摄像头的 MJPEG 视频流
- **唯一显示检测框标注的画面**
- 标注框颜色按类型区分：

| 检测类型 | 框颜色 | 标签 |
|---------|--------|------|
| fire | `#ff0000` | fire |
| smoke | `#ff6600` | smoke |
| uniform | `#00ff00` | uniform |
| mask | `#00ccff` | mask |
| cigarette | `#ff00ff` | cigarette |
| sleep | `#ffff00` | sleep |

### 2.3 副画面

- 右侧纵向排列，固定数量（默认 6 个）
- 每个显示一个摄像头的 MJPEG 视频流
- **不显示检测框，原图渲染**
- 底部翻页控制：`<` 上一页 / `页码` / `>` 下一页
- 点击任意副画面：**该画面与主画面交换**（摄像头互换）

### 2.4 画框配置面板

**全局唯一配置**，不绑定任何摄像头。

```
┌──────────────────────────────┐
│ 画框配置                      │
│                              │
│ ☑ fire    ☑ smoke           │
│ ☑ uniform ☑ mask            │
│ ☑ cigarette ☑ sleep         │
│                              │
│ [全选] [全不选]              │
└──────────────────────────────┘
```

- 6 个检测类型的复选框
- 所有类型始终可勾选（不受摄像头是否启用该类型影响）
- 但只有**当前摄像头启用了该类型**且**勾选了画框**时，才会实际渲染框
- 默认状态：全不选
- 持久化到后端（`POST /settings` 的 `overlay_types` 字段）

### 2.5 告警列表侧边栏

- 按级别分色：P0 红色 / P1 橙色
- 显示最近 N 条告警（时间、摄像头、类型）
- 点击可跳转对应摄像头为主画面

### 2.6 状态栏

- 在线摄像头数
- 检测中摄像头数
- 总告警次数
- 系统运行时间

### 2.7 API 依赖

| API | 用途 |
|-----|------|
| `GET /cameras` | 获取摄像头列表及状态 |
| `GET /cameras/{id}/stream` | 主/副画面 MJPEG 流 |
| `GET /settings` | 读取全局画框配置 |
| `POST /settings` | 保存画框配置 |
| `GET /alerts?limit=20` | 实时告警列表 |
| `GET /status` | 系统状态统计 |

## 3. 记录查询 (Records)

### 3.1 布局结构

```
┌──────────────────────────────────────────────────────────────┐
│  Header: Sentry 安全监控系统   [监控中心] [记录查询] [系统设置]   │
├──────────────────────────────────────────────────────────────┤
│  [手动刷新]                                                   │
├──────────────────────────────────────────────────────────────┤
│  统计摘要: 总记录: N | P0: X | P1: Y | 误报率: Z%             │
├──────────────────────────────────────────────────────────────┤
│  筛选器: [日期范围] [级别] [类型] [状态] [摄像头多选]          │
├──────────────────────────────────────────────────────────────┤
│  ┌────┬──────────┬──────────┬──────┬────────┬────────┬─────┐ │
│  │ 多选│  时间    │  摄像头   │ 类型 │ 级别   │ 状态   │ 操作│ │
│  ├────┼──────────┼──────────┼──────┼────────┼────────┼─────┤ │
│  │ ☐  │ 14:32:01 │ cam_01   │ fire │ P0     │ alerted│ 查看│ │
│  │ ☐  │ 14:28:15 │ cam_02   │ mask │ P1     │ pending│ 查看│ │
│  └────┴──────────┴──────────┴──────┴────────┴────────┴─────┘ │
├──────────────────────────────────────────────────────────────┤
│  分页: [<] 第 1/5 页 [>]    [批量删除] [批量标记误报]        │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 筛选器

| 筛选条件 | 控件类型 | 选项 |
|---------|---------|------|
| 日期范围 | 日期选择器（起止） | 默认今天 |
| 级别 | 下拉单选 | P0 / P1 / 全部 |
| 类型 | 下拉单选 | fire/smoke/uniform/mask/cigarette/sleep/全部 |
| 状态 | 下拉单选 | alerted/confirmed/false_positive/rejected/pending/全部 |
| 摄像头 | 下拉多选 | 全部摄像头（可多选） |

### 3.3 记录列表

表格列：
- 多选框（用于批量操作）
- 时间（精确到秒）
- 摄像头名称
- 检测类型
- 级别（P0/P1 带颜色标签）
- 状态（带颜色标签）
- 操作按钮（查看详情）

点击整行或"查看"按钮打开详情窗口。

### 3.4 记录详情窗口

弹窗/抽屉形式，包含两个区域：

**A. 快照区域**
- 显示触发告警时的主帧图片
- 显示检测框叠加（如果有 boxes 数据）
- 显示基本信息：时间、摄像头、类型、级别、置信度、VLM复核结果

**B. 帧查看器（关键功能）**
- 专用于查看多帧记录（如 sleep 类型的 consecutive_required 帧）
- 布局：

```
┌────────────────────────────────────────────┐
│  帧查看器                                   │
│  ┌────────────────────────────────────┐   │
│  │                                    │   │
│  │         当前帧大图显示              │   │
│  │                                    │   │
│  └────────────────────────────────────┘   │
│  [播放] [暂停] [进度条] 帧 3/10           │
│  ┌────┬────┬────┬────┬────┬────┐         │
│  │帧1 │帧2 │帧3 │帧4 │帧5 │帧6 │ ...     │
│  └────┴────┴────┴────┴────┴────┘         │
└────────────────────────────────────────────┘
```

- 播放/暂停按钮：自动轮播所有帧
- 进度条：拖动跳转
- 底部缩略图：点击直接跳转到对应帧
- 帧信息：当前帧序号 / 总帧数

### 3.5 批量操作

- 多选记录后：
  - 批量删除：弹出确认对话框
  - 批量标记误报：将状态改为 `false_positive`

### 3.6 API 依赖

| API | 用途 |
|-----|------|
| `GET /alerts` | 获取告警记录列表（支持筛选、分页） |
| `GET /alerts/stats` | 统计摘要 |
| `GET /record/{id}` | 单条记录详情 |
| `GET /record/{id}/snapshot` | 快照图片 |
| `GET /record/{id}/frames` | 帧序列图片 |
| `POST /alerts/{id}/ignore` | 标记误报 |
| `DELETE /alerts/batch` | 批量删除 |

## 4. 系统设置 (Settings)

### 4.1 布局结构

```
┌──────────────────────────────────────────────────────────────┐
│  Header: Sentry 安全监控系统   [监控中心] [记录查询] [系统设置]   │
├──────────────────────────────────────────────────────────────┤
│  [全局参数] [画框配置] [摄像头管理] [模型状态] [系统操作]       │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  根据选中标签页显示对应内容                                    │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 标签页：全局参数

可编辑的全局配置项：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 通用检测间隔 | number | 1.0 | 秒 |
| 睡岗检测间隔 | number | 60.0 | 秒 |
| VLM最大并发 | number | 3 | |
| VLM巡检间隔 | number | 30 | 秒，0=关闭 |
| P0告警冷却 | number | 10 | 秒 |
| P1告警冷却 | number | 3 | 秒 |
| 最大记录数 | number | 100 | |
| 最大存储空间 | number | 500 | MB |
| 快照质量 | number | 70 | 1-100 |
| 帧质量 | number | 60 | 1-100 |
| 内存回收阈值 | number | 80 | % |

底部：【保存】按钮，保存后实时生效并持久化。

### 4.3 标签页：画框配置

与监控页面的画框配置面板功能一致，只是放在设置页作为独立配置入口。

- 6 个检测类型的复选框
- 默认全不选
- 【保存】持久化

### 4.4 标签页：摄像头管理

**A. 摄像头列表**

表格列：ID、名称、源地址、类型、启用状态、操作（编辑/删除）

**B. 单摄像头编辑**

点击编辑展开/弹窗：

```
┌─────────────────────────────┐
│ 编辑摄像头: cam_01           │
│                             │
│ 名称: [________]            │
│ 源地址: [________]          │
│ 源类型: [下拉]              │
│ 分辨率: [宽] x [高]         │
│ 启用: [开关]                │
│                             │
│ --- 检测类型配置 ---        │
│                             │
│ fire:     [开关] 间隔[s] 阈值 连续次数 │
│ smoke:    [开关] 间隔[s] 阈值 连续次数 │
│ uniform:  [开关] 间隔[s] 阈值 观察窗口 │
│ mask:     [开关] 间隔[s] 阈值 连续次数 │
│ cigarette:[开关] 间隔[s] 阈值 连续次数 │
│ sleep:    [开关] 间隔[s] 阈值 连续次数 │
│                             │
│ [保存] [取消]               │
└─────────────────────────────┘
```

**C. 批量配置**

- 多选摄像头（表格左侧复选框）
- 点击【批量配置】按钮
- 弹窗中统一设置：哪些检测类型启用、统一阈值/间隔
- 应用到所有选中摄像头

**D. 添加摄像头**

- 表单：ID、名称、源地址、源类型、分辨率
- 添加后默认启用，检测类型使用全局默认值

### 4.5 标签页：模型状态

- 已加载模型列表（模型名称、类型、加载时间、状态）
- 运行模式：CPU / NPU
- NPU 核心数（如果是 NPU 模式）
- 懒加载提示：未启用的类型对应模型显示"未加载"

### 4.6 标签页：系统操作

- 【重启检测服务】按钮：确认后调用 API 重启后端检测线程

### 4.7 API 依赖

| API | 用途 |
|-----|------|
| `GET /settings` | 读取全局配置 |
| `POST /settings` | 保存全局配置 |
| `GET /cameras` | 摄像头列表 |
| `POST /cameras/add` | 添加摄像头 |
| `POST /cameras/{id}/config` | 修改单摄像头配置 |
| `POST /cameras/batch-config` | 批量修改摄像头配置 |
| `DELETE /cameras/{id}` | 删除摄像头 |
| `GET /detector/models` | 已加载模型状态 |
| `POST /system/restart` | 重启检测服务 |

## 5. 数据流与状态管理

### 5.1 前端状态（Vue3 Composition API）

```javascript
// 全局共享状态（ Pinia / reactive ）
const globalState = reactive({
  cameras: [],           // 摄像头列表
  overlayTypes: [],      // 全局画框配置 ['fire', 'mask', ...]
  alerts: [],            // 实时告警列表
  settings: {},          // 全局配置
  detectorStatus: null,  // 检测器状态
});
```

### 5.2 监控页面状态

```javascript
const monitorState = reactive({
  mainCameraId: null,    // 主画面摄像头ID
  subCameraIds: [],      // 当前页副画面摄像头ID列表
  subPageIndex: 0,       // 副画面当前页码
  subPageSize: 6,        // 每页副画面数量
});
```

### 5.3 主副画面交换逻辑

```javascript
function swapMainSub(subIndex) {
  const subCamId = monitorState.subCameraIds[subIndex];
  if (!subCamId) return;

  const oldMain = monitorState.mainCameraId;
  monitorState.mainCameraId = subCamId;

  // 替换副画面数组中的对应位置
  monitorState.subCameraIds[subIndex] = oldMain;
}
```

### 5.4 画框渲染逻辑

```javascript
// 后端 MJPEG 流已包含标注框
// 前端只需控制：主画面流地址 vs 副画面流地址

// 主画面（带框）
`/cameras/${mainCameraId}/stream`

// 副画面（原图，不带框）
`/cameras/${subCamId}/stream?raw=1`
// 或如果后端 overlay 仅作用于主画面，则副画面天然无框
```

**后端逻辑**：`main_multi.py` 的 `_overlay_loop` 只给当前 `mainCameraId` 对应的流画框，其余摄像头推送原图到 `stream_server`。

## 7. 响应式设计

### 7.1 桌面端（≥1280px）
- 主画面 + 右侧 6 个副画面
- 所有功能完整展示

### 7.2 平板端（768px - 1279px）
- 主画面全宽
- 副画面改为底部横向排列，2-3 个可见，支持左右滑动翻页

### 7.3 手机端（<768px）
- 主画面全屏
- 副画面隐藏或改为底部小条（点击展开选择器）
- 画框配置、告警列表放入抽屉/弹窗

## 9. 实现顺序

| 步骤 | 内容 | 文件 |
|------|------|------|
| 1 | 重写监控页面：主副布局、翻页、交换 | `frontend/multi.html` |
| 2 | 后端画框配置改为全局 | `backend/main_multi.py` |
| 3 | 重写记录页面：筛选、详情、帧查看器 | `frontend/records.html` |
| 4 | 新建设置页面 | `frontend/settings.html` |
| 5 | 提取公共样式到 style.css | `frontend/style.css` |
| 6 | 统一导航栏组件 | 嵌入各页面 |
