# 视频诊断系统 (Sentry Safety) 产品与功能说明文档

## 一、 产品定位与核心价值

**视频诊断系统（Sentry Safety）** 是一套面向**工业园区、智能工厂、施工工地、变电站、控制室与值守机房**等安全生产场景的**端云协同多路智能视频分析与告警管理系统**。

### 1.1 核心解决的痛点
1. **传统视觉算法误报率高**：水雾、反光、车灯、阴影、晚霞等环境因素极易触发传统 CV 算法误报，造成值班人员警觉疲劳（“狼来了”效应）。
2. **定制算法开发周期长**：业务需求多样且易变（如“穿了工服但未戴安全帽”、“必须两人同行动作”等），传统方案需要反复重新标注训练复合模型。
3. **边缘算力瓶颈与多路并发冲突**：在多路 1080P/4K 视频流接入时，边缘盒子常面临视频解码卡顿、显存/内存溢出以及多模型排队延迟严重等问题。

### 1.2 核心产品价值
- **“轻量 CV 初筛 + VLM 大模型复核”双阶段过滤**：结合边缘轻量模型的毫秒级响应与多模态大模型的语义理解能力，实现高召回、超低误报的工业级告警准确率。
- **模型与算法完全解耦 + 空间关系规则引擎**：基础原子目标检测模型（人、安全帽、反光背心等）一次训练长期复用；业务逻辑通过可视化规则引擎（包含、重叠、上方、数量、缺失）自由拼装，零代码适配复杂新场景。
- **异构硬件算力深度适配**：支持国产嵌入式边缘端（瑞芯微 RK3588 3-NPU 多核调度）及云端/工控机 GPU（NVIDIA NVDEC 硬解码、动态推理队列、FP16 精度加速）。

## 三、 功能模块详解

### 3.1 实时监控中心（Monitor）
* **多路视频流并发监控**：
  * 支持多路 RTSP 网络摄像头及本地视频源的网格化平铺展示。
  * 提供单路画面放大、全屏沉浸式巡检与画面状态指示。
* **实时智能标注渲染**：
  * 内置 CJK 中文渲染引擎，动态在画面上绘制目标标定框、置信度数值及告警类别标签。
  * 根据检测算法类型自动匹配专属颜色徽章，视觉辨识度高。
* **多区域 / 多边形 ROI 交互绘制**：
  * 支持在视频画面上自由绘制任意形状的多边形或矩形检测区域（ROI）。
  * 支持“正向检测”（仅在区域内触发报警）与“反向排除”（屏蔽特定反光或作业区域的干扰）。
* **快速算法通道启停**：
  * 侧边栏提供每路摄像头的算法独立开关，支持现场巡检时动态启用或暂停指定检测项。
* **实时事件流与告警弹窗**：
  * 告警发生时，右侧实时事件列表自动置顶刷新，支持声光报警提示与高亮弹窗。

---

### 3.2 告警记录中心（Records）
* **多维数据统计看板**：
  * 顶部直观统计今日告警总数、各类型告警占比分布、大模型复核通过率及误报率指标。
* **多条件组合检索过滤**：
  * 支持按时间区间（起止日期与时间）、摄像头通道、告警类型、告警等级、复核状态（待复核/已确认/系统误报/人工标记）进行多维度联合过滤。
* **告警多媒体详情抽屉**：
  * **现场高清快照**：查看告警触发瞬间带有标定框的高清现场抓拍图。
  * **上下文连续抽帧**：提供告警前后 5~15 张连续时序抽帧相册，清晰回溯违规行为的发生全过程。
  * **浏览器端即时视频回放**：系统自动剪辑生成告警前后的轻量级视频片段（VP8 Web 兼容格式），无需下载即可在浏览器内流畅播放。
  * **VLM 大模型研判详情**：清晰呈现大模型审核结论（真实违规 / 误报）、置信度得分及详细的文字分析理由。
* **人工闭环复核机制**：
  * 允许安全管理人员对初筛/大模型结论进行二次确认（“确认属实”或“标记误报”），操作记录同步持久化并可导出报表。

---

### 3.3 算法管理（Algorithms）
* **算法全生命周期配置**：
  * 支持内置算法与自定义业务算法的新增、编辑、启停、参数调整与删除。
* **运行参数精细化调节**：
  * 支持配置算法关联的基础模型、推理执行周期（秒）、检测置信度阈值、触发冷却时间（秒）以及连续命中确认帧数（防抖机制）。
* **可视化空间关系规则引擎（Relation Rule Engine）**：
  * **关系算子（Relation Ops）**：`overlap`（重叠/IoU 阈值）、`contain`（包含/面积占比）、`above`（位于上方）、`not_overlap`（无重叠）、`not_contain`（不包含）。
  * **全局算子（Global Ops）**：`exists`（存在目标）、`absent`（目标缺失）、`count`（数量比较：大于、小于、等于、超出安全区间等）。
  * **多条件逻辑组合**：支持“条件组间为 OR，组内条件为 AND”的复杂规则组合（例如：*【检测到人 且 未穿反光背心】或【检测到人 且 处于危险禁行区】*）。
* **VLM 复核提示词定制**：
  * 针对不同算法可自定义专属的复核 Prompt，精准指导大模型排除特定场景的干扰项。

---

### 3.4 模型管理（Models）
* **模型与算法完全解耦**：
  * 底层模型专注于“通用目标识别”（如人体检测模型、安全帽/背心防护用品模型、烟雾火焰模型等），上层算法专注于“业务规则拼装”。
* **权重文件管理与元数据自动解析**：
  * 支持上传 `.pt`（PyTorch / Ultralytics YOLO）及 `.rknn`（瑞芯微 NPU 格式）模型文件。
  * 上传后自动解析模型元数据（包括类别清单 `class_names`、类别 ID 映射、输入张量尺寸等）。
* **一键热替换**：
  * 支持在服务运行过程中一键更换指定模型的权重文件，无需重启整个后端服务。

---

### 3.5 系统设置与硬件调度（Settings）
* **摄像头通道统一管理**：
  * 管理各路摄像头的 RTSP 连接串、显示名称、目标分辨率、帧率及断线自动重连策略（支持无限重连，适配工业现场网络抖动）。
* **异构硬件加速与自适应调度**：
  * **RK3588 NPU 模式**：深度利用 3 个独立 NPU 核心，支持核心自动负载均衡与核心绑定策略（`CorePinnedStrategy` / `SerialStrategy`）。
  * **NVIDIA GPU 模式**：支持 NVDEC 硬件视频解码、动态推理队列及 FP16 半精度推理加速。
  * **显示与检测频率分离**：主画面显示检测刷新频率可在 0.1~10 秒范围内独立配置，兼顾流畅视觉与边缘算力节约。

---

### 3.6 外部系统集成层（Integrations）
* **西艾氟 (Xilu) OpenAPI 规范对接**：
  * 严格遵循 `/cvApi/open/api/cv/*` 接口规范。
  * 提供模型分页查询、告警记录分页查询、告警统计数量汇总等标准化接口。
* **国经与第三方 WebHook 广播分发**：
  * 告警产生（Created）及大模型复核完成（Reviewed）时，异步广播推送到配置的第三方系统。
  * 各推送通道完全隔离，单通道异常不会影响系统主流程与其他系统推送。

## 四、 典型应用场景示例

| 场景分类 | 适用检测算法 | 核心判断逻辑与 VLM 复核作用 |
| :--- | :--- | :--- |
| **PPE 穿戴合规** | 安全帽佩戴检测、工服/反光背心检测、口罩佩戴检测 | 利用规则引擎判定“人体”与“安全帽/背心”的空间重叠与包含关系；VLM 智能排除饮水用餐暂时摘下口罩、手持反光工具等伪误报。 |
| **值班行为规范** | 睡岗/趴桌检测、脱岗离岗检测 | 结合俯视/平视姿态与持续静止时长判定；VLM 深度理解人员姿态，精准排除低头书写、看手机等正常值班操作。 |
| **消防与园区安全** | 明火检测、烟雾检测 | 结合静态光斑差异过滤排除常亮指示灯；VLM 进一步排除晚霞、夕阳射入、红色安全帽反光、水蒸气与现场扬尘。 |
| **危险区域管控** | 电子围栏越界、禁行区逗留、区域超员 | 结合多边形 ROI 区域与人员检测框，判断目标是否进入危险区域或区域内作业人数是否超出/不足安全限制。 |

## 五、 技术栈一览

- **后端架构**：Python 3.12、FastAPI、Uvicorn、OpenCV、NumPy、Pillow、PyTorch、Ultralytics YOLO
- **硬件与 AI 加速**：RKNN-Toolkit2 (RK3588 NPU)、NVIDIA CUDA / NVDEC 硬件解码、大模型 VLM（火山引擎豆包 Ark / 阿里云百炼 DashScope）
- **前端架构**：Vue 3、原生 HTML5 / CSS3（现代 Glass-Clay 设计风格）、Fetch API / EventSource
- **数据持久化**：JSON 结构化存储、本地视频片段切片与帧图片目录归档
